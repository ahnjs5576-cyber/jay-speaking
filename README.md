# 인터뷰 따라 말하기

인터뷰 대본을 넣으면 인터뷰받는 사람의 대사로 듣고 따라 말하며 발음을 체크하는 쉐도잉 연습 앱입니다.

- 대본(.txt, 여러 개 한 번에 가능)을 열면 인터뷰받는 사람을 자동으로 찾아 그 사람의 대사만 문장 단위로 추출
- 인터뷰를 여러 개 저장해 두고 골라서 연습, 연습할 사람 변경 가능
- 원어민 듣기(속도·목소리 선택), 단어 눌러 듣기
- 브라우저 음성 인식으로 따라 말한 문장을 채점하고 틀린 단어와 발음 팁 표시
- 문법 체크(LanguageTool)와 고친 문장으로 연습

휴대폰에서는 크롬(안드로이드) 또는 사파리(아이폰)로 https 주소를 열어야 마이크가 동작합니다.
대본과 연습 기록은 각 기기의 브라우저에만 저장됩니다.
