# 인터뷰 따라 말하기

인터뷰 대본을 넣으면 인터뷰받는 사람의 대사로 듣고 따라 말하며 발음을 체크하는 쉐도잉 연습 앱입니다.

- 대본(.txt, 여러 개 한 번에 가능)을 열면 인터뷰받는 사람을 자동으로 찾아 그 사람의 대사만 문장 단위로 추출
- 인터뷰를 여러 개 저장해 두고 골라서 연습, 연습할 사람 변경 가능
- 원어민 듣기(속도·목소리 선택), 단어 눌러 듣기
- 브라우저 음성 인식으로 따라 말한 문장을 채점하고 틀린 단어와 발음 팁 표시
- 문법 체크(LanguageTool)와 고친 문장으로 연습

휴대폰에서는 크롬(안드로이드) 또는 사파리(아이폰)로 https 주소를 열어야 마이크가 동작합니다.
대본과 연습 기록은 각 기기의 브라우저에만 저장됩니다.

# 영어 쓰기 연습 (`writing.html`)

"쓰고 → 바로 피드백 받고 → 다시 써 보는" 루프를 짧게 만든 영어 쓰기 연습 앱입니다.

- **레벨 B2 이상, 자동 조정**: 번역·확장·일기 각각 B2에서 시작해 B2 → C1 → C2로 움직임. 같은 레벨에서 처음 쓴 글의 최근 3번 평균 85점 이상이면 올라가고, 최근 2번 평균 60점 미만이면 내려감 (B2 아래로는 안 내려감). 채점도 그 레벨의 기준으로 함
- **한→영 번역**: 레벨별 한국어 문장 또는 직접 넣은 문장을 영작하면 채점하고, 정답이 하나가 아니라는 걸 보여 주도록 여러 정답 예시를 함께 보여 줌
- **문장 확장**: 짧은 문장을 레벨에 맞는 구조(관계사절·분사구 → 입장·완곡 표현 → 도치·명사화)로 확장 (단어 수 목표 표시)
- **오늘의 일기**: 레벨에 맞는 주제로 B2 3~5문장, C1 4~6문장, C2 5~7문장 쓰기
- **AI 새 문제**: 준비된 문제를 다 풀면 Claude가 지금 레벨에 맞는 새 문제를 만들어 줌
- **피드백**: 틀린 부분마다 "왜 틀렸는지 + 더 자연스러운 표현"을 보여 주고, 문법 오류(빨강)·어색한 표현(주황)·더 고급 표현(파랑)을 색으로 구분. 한국어 때문에 생기기 쉬운 실수는 그렇다고 알려 주고, 고침마다 추가 질문을 할 수 있음
- **다시 쓰기**: 첨삭받은 글은 다음 날 '다시 쓰기'에 올라옴. 피드백 없이 다시 쓰면 점수 변화, 달라진 단어, 고친 실수와 반복한 실수를 보여 줌. 아직 틀린 곳이 있으면 3일 뒤 다시 올라옴. 지난 글의 피드백도 다시 볼 수 있음
- **내 약점 리포트**: 관사·시제·전치사·어조·연결 등 17가지 유형을 누적하고, 최근 2주 100단어당 횟수와 추세를 보여 줌. 유형마다 '집중 연습' 3문제를 만들어 줌 (연결·어조·간결함은 짧은 글 다듬기)
- **복습 카드**: 내가 틀린 문장(문맥 그대로)과 새 표현을 카드로 저장해 1·3·7·14·30일 간격으로 복습. 답을 쓰면 자동으로 채점. 새 카드는 하루 10장까지
- **꾸준함**: 연속 작성일, 최근 2주 기록, 최근 8주 주간 단어 수 그래프. 쓰던 글은 새로고침해도 남아 있음

**claude.ai에서 쓰기 (API 키 필요 없음)**: 이 페이지를 claude.ai 아티팩트로 열면 보는 사람의 Claude 계정으로 피드백을 받습니다.
처음 피드백을 받을 때 Claude 사용을 허용하면 되고, 사용량은 그 사람의 Claude 요금제에서 차감됩니다.
기록은 그 사람의 계정에 본인만 볼 수 있게 저장되어 다른 기기에서도 이어집니다.

**그 밖의 곳에서 열 때**: Claude API(`claude-opus-5-5`)를 직접 부릅니다. 처음 쓸 때 "API 키 설정"에서 본인의 Anthropic API 키를 넣으세요.
키는 그 기기의 브라우저에만 저장되고 Anthropic API로만 전송됩니다. 글과 기록도 브라우저에만 저장됩니다.
